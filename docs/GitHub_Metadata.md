## 4. Portfolio Description (Short - 1 Paragraph)
> **Network Intrusion Detection System (NIDS)** is a full-stack Machine Learning security application that analyzes network flow traffic and categorizes attacks into five major threat classes (Normal, DOS, PROBE, R2L, U2R). Built with Flask 3.1, XGBoost, and scikit-learn, the platform features a dual-pipeline architecture supporting both high-accuracy batch training and memory-bounded Out-of-Core streaming via Welford's algorithm. Deployed using Docker and Gunicorn WSGI.

---

## 5. Portfolio Summary (Detailed)
> Traditional signature-based intrusion detection tools fail against zero-day exploits and high-velocity network streams. This project delivers an end-to-end Machine Learning web application built on the NSL-KDD benchmark dataset. It features cost-sensitive XGBoost classification to combat severe class imbalance (U2R and R2L attacks), a 100% vectorized out-of-core feature scaling engine, hardened Flask REST APIs with custom error handlers, and interactive SOC analytics dashboards.
